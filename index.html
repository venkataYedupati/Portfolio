BMS Firmware Simulator

An automotive Battery Management System ECU simulated end to end in C: a 2-state Kalman filter estimating state of charge and current-sensor bias, a debounced/latching fault state machine, and CAN-FD reporting against a cantools-verified DBC. OS calls and CAN transport sit behind clean interfaces with two real ports — FreeRTOS on QEMU and a SocketCAN backend — plus libFuzzer fuzzing, ASan/UBSan/TSan, and coverage in CI. No hardware required.

fastgemm

A CUDA SGEMM kernel library optimized stage by stage from a naive baseline toward cuBLAS-competitive throughput. Each stage is motivated by a specific Nsight Compute metric from the previous one, and every kernel is checked for numerical correctness against cublasSgemm in pedantic-math mode across a matrix-size sweep.

CUDAC++Nsight Compute CMakeGPU Performance
